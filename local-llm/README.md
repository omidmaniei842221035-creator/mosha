# موتور مکالمهٔ محلی

این پوشه خروجی مرورگری WebLLM را برای اجرای مدل Qwen3 روی WebGPU نگه می‌دارد. inference در Worker خود مرورگر انجام می‌شود؛ برنامه پیام‌ها را به API گفت‌وگوی ابری نمی‌فرستد.

## بارگیری وزن مدل

مدل‌ها عمداً داخل مخزن کپی نشده‌اند: وزن هرکدام از نسخه‌های ۱٫۷B، ۴B و ۸B چندگیگابایت است. با انتخاب مدل و فشردن «بارگذاری / دریافت مدل»، WebLLM در بارگیری نخست وزن‌ها، پیکربندی و WebAssembly بهینه‌شدهٔ همان مدل را از نشانی‌های ثابتِ ثبت‌شده در پیکربندی WebLLM دریافت می‌کند. پس از ذخیره‌شدن این فایل‌ها در OPFS یا Cache Storage همان origin، اجرای مکالمه محلی است و به شبکه نیاز ندارد. دریافت اولیه به اینترنت، فضای ذخیره‌سازی کافی، مرورگر Edge/Chrome به‌روز و WebGPU سازگار احتیاج دارد.

مدل‌ها: `Qwen3-4B-q4f16_1-MLC` (گزینهٔ پیش‌فرض با کیفیت بالاتر)، `Qwen3-8B-q4f16_1-MLC` (بزرگ‌ترین/قوی‌ترین گزینهٔ فهرست برای GPU پرقدرت) و `Qwen3-1.7B-q4f16_1-MLC` (سبک‌تر برای دستگاه‌های محدودتر). مقدار حافظهٔ گرافیکی تخمینی پیکربندی WebLLM برای ۱٫۷B، ۴B و ۸B به‌ترتیب حدود ۲۰۳۷، ۳۴۳۲ و ۵۶۹۶ مگابایت است. این برآورد حداقل قطعی یا تضمین سازگاری با GPU خاصی نیست؛ برنامهٔ مرورگر و نمایشگر هم حافظه مصرف می‌کنند.

## نسخه و مجوز موتور

باندل‌ها با `@mlc-ai/web-llm@0.2.89` و `esbuild@0.25.5` ساخته شده‌اند. وابستگی‌های زمان اجرا در خروجی شامل `@mlc-ai/web-runtime@0.28.0-dev2`، `@mlc-ai/web-tokenizers@0.1.6` و `@mlc-ai/web-xgrammar@0.1.27` است. مجوزهای Apache-2.0 و MIT و اطلاعیهٔ وابستگی‌ها در `LICENSE-APACHE-2.0.txt` و این README ثبت شده‌اند.

## حریم خصوصی و محدودیت‌ها

- متن پیام‌ها فقط به مدل محلیِ در حال اجرا روی همین دستگاه داده می‌شود؛ در بارگیری نخست فقط درخواست دریافت فایل‌های مدل و runtime به منابع توزیع مدل می‌رود.
- فایل‌های مدل در فضای خصوصی همان origin مرورگر (OPFS یا Cache Storage) قرار می‌گیرند. تغییر پورت localhost یا مرورگر، فضای جداگانه‌ای می‌سازد؛ پاک‌کردن داده‌های سایت هم ممکن است فایل‌های مدل را حذف کند.
- Qwen3 محلی از مدل‌های ابری بسیار بزرگ ضعیف‌تر است و ممکن است خطا کند. پاسخ‌های بانکی را با سند اصلی و کارشناس تطبیق دهید؛ بازیابی محلی سندها فقط متن‌های مرتبط را فراهم می‌کند و تضمین صحت پاسخ مدل نیست.
- بدون GPU/WebGPU سازگار، مکالمهٔ مولد فعال نمی‌شود؛ در آن حالت جست‌وجوی آفلاین موجود در «دستیار هوشمند بخشنامه‌ها» همچنان جداگانه قابل استفاده است.
